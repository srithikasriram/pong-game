# pong-game
Two-player pong game

Features
- UI contains two paddles -- right controlled by arrow keys and left controlled by WASD.
- Ball moves in the middle.
- Paddle can be moved and hit ball to make it bounce.
- If ball extends behind paddle, then the ball position is reset and score is updated.

Technologies:
- Python
- Libraries: Turtle, Random

What I Learned:
- GUI development with Turtle
- Object-Oriented Programming
